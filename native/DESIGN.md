# 原生桌面设计规范

当前用于原生待办正式实现。布局和交互遵循已确认方案，视觉细节继续结合真实窗口与内容由用户审阅；逻辑、持久化与异常路径持续验证。

原生窗口以快速记录与处理任务为核心，使用克制的工具外壳、紧凑列表和系统输入行为。Things 的轻侧栏、Linear 的列表密度、用户指定的 Codex 风格提供方向，不逐像素复刻。

- 使用 GPUI Kit 控件、系统窗口控件及系统 UI 字体，颜色来自 `Theme` 的语义令牌。不要：在业务视图硬编码颜色或另写一套基础控件。
- 默认窗口 1080×720，最小 720×480；正文 14、页面标题 20，内容边距统一 6 个刻度，字段间距 4、字段标签间距 2、同行控件间距 2–3。窗口尺寸为逻辑像素，布局用 GPUI Kit rem 刻度与主题语义令牌。
- 待办壳层侧栏约 200–224，包含摘要的任务行 3.5rem；任务不包成卡片，不增加仪表盘或统计概览。分类与优先级用文字和 Tag/Flag 图标，优先级高/中/低分别用 danger/warning/info，颜色只辅助识别。
- 创建、编辑、详情按同一窗口空间规则展示：窗口达到 70rem 时放入右侧 34rem 面板，其余使用居中 34rem 弹窗；弹窗距视口边缘至少 2.5rem。编辑弹窗优选高 30rem，阅读 26rem，受视口限制。切换保留原输入实体、选区、历史和草稿；详情使用可选取的阅读内容，不渲染可聚焦编辑输入。
- 分类与优先级放在等宽两列，标签在各自控件上方；日期与可选时刻同行。备注独占剩余高度，正文最少 4rem，长正文在备注内部滚动，小窗口由字段区域滚动保证保存可达。工具栏归备注内部，字数在右侧。
- 搜索、优先级和分类放同一工具栏，搜索文字区与两个筛选按钮分别持有边框、焦点和键盘行为。筛选按当前语言最长候选宽度适配，超长按钮不超过 12rem，菜单受视口限制；空间不足只显示图标并保留 tooltip。不要：让筛选聚焦状态高亮整个搜索输入。
- 设置标签与控件同排，语言与外观采用相同宽度下拉，不截断或缩小热区。
- 详情以任务标题直接作为标题栏标题，右上角仅关闭；标题栏和底部操作均采用默认按钮规格，图标随控件规格一致。标签与已有计划/状态时间同行，确实放不下才换行；没有计划时间不显示“未安排”，没有任何元数据不预留空行。底部保留一个完成/恢复主操作、编辑及更多，完整创建/更新时间进入更多的“任务信息”子菜单，废弃、删除同属更多，避免两个恢复入口。状态写入成功后关闭详情并回归列表，失败保留原状态及正文，错误就近显示，等待事务时禁止重复操作。
- 所有可见及可访问文案使用 `native/locales/` 的稳定语义键；语言名称使用自名。切换语言和外观保留输入实体，不重建草稿。
- 高频输入即时响应，不做启动动画；保持基础控件的焦点样式与键盘行为，不拦截输入法组词中的 Enter；组词时 Esc 只取消标记。离开脏草稿使用居中 24rem 确认框，仅“放弃修改”“保存更改”；关闭或 Escape 返回编辑，保存失败保留草稿和错误，提交成功才离开。
- 破坏操作二次确认，错误靠近相关内容，常规保存成功静默。不要：把读取失败当作空列表或自动删除损坏数据库。
- 图片硬限制通过顶部居中 Notification 提示，不改变正文；图片处理占位保留实际进度与恢复动作。Lucide 图标从统一原生资源源打包，不以 Unicode 或零散图标文件替代。
- 图文任务行在既有行高内展示 2rem 首图缩略图与图片数量，图片读取失败保留占位。复制图片归备注右键菜单，按正文顺序列出，不增加常驻详情入口；跨任务图文粘贴保留原选区，处理中继续编辑使旧粘贴失效。

例外：原生版独立采用 GPUI/Cargo/`rust-i18n`，不使用根 DESIGN.md 的 shadcn、Tailwind、Web 页面骨架及移动视口矩阵；React 继续遵守原规范。
