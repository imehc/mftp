# 独立验证目录

跨模块回归和工程检查集中在此，前端单元测试仍与 src 源码同目录，Rust 测试继续放独立文件。构建、版本管理和维护工具保留在 scripts。

| 目录                         | 用途                                                   | 运行入口                                                                                          |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| [browser](browser/README.md) | 隔离浏览器回归及 HTML/TSX 夹具                         | `pnpm qa:browser`，可追加组名                                                                     |
| checks                       | React 版本、离线解码器、产物预算、Android 插件编译检查 | `pnpm react:check`、`pnpm model:offline-check`、`pnpm build:budget`、`pnpm android:plugins:check` |

命令在仓库根目录执行。预算检查需要先构建；Android 插件环境见 [Android 说明](../docs/android.md)。浏览器测试不进入生产包，输出仍写入独立临时目录。原生验收需另行确认，编译和浏览器模拟不算原生通过。
