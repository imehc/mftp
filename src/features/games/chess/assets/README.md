# 国际象棋棋具资源

`staunton.glb` 包含王、后、象、马、车、兵六种原创 Staunton 造型：王的双轴十字冠、后的齿冠、象的斜槽、车的垛口、马头和兵的圆顶分别保留识别特征。六类几何各保存一套，运行时复用并分配浅色黄杨木和深色染黑木两种材质。

`wood-grain.png`（1024 × 1024）与 `wood-roughness.png`（512 × 512）为同一脚本生成的方向性木纹和粗糙度贴图。模型与纹理均在本地生成，无第三方模型、外部图片或在线下载依赖。

建模与贴图源文件为仓库内的 `scripts/assets/chess_models.py`，可在 Blender 5.2 中重建：

```sh
blender --background --factory-startup --python scripts/assets/chess_models.py
```

只重建贴图时，在命令末尾加入 `-- --textures-only`。脚本在隔离后台场景运行；不要在含有个人作品的交互场景中直接执行。完整运行还会在本地忽略的 `.impeccable/review/chess/` 保存源场景和造型预览。

GLB 携带 UV、法线与 `COLOR_0` 顶点颜色，不携带材质。顶点颜色保存建模时计算的局部遮蔽，使冠部和刻槽在顶视照明下保留深度线索；它不是完整场景的环境遮蔽。`render/assets.ts` 创建 PBR 材质，并启用顶点颜色。粗糙度贴图同时用于细微凹凸，没有单独的法线贴图。

资源通过模块内 URL 引用随应用离线分发，进入国际象棋时加载，运行时需要 WebGL。棋格、木框、坐标、灯光和名称辅助由本模块创建。默认使用零倾角正上方正交相机；立体预设使用透视相机，全部棋具共享相应相机。名称辅助默认开启，可在更多菜单关闭。生成的 Blender 预览用于查看造型，不定义应用的镜头、光照或最终材质。
